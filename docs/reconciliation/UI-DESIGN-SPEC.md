## Brand & Style

This design system establishes a high-density, authoritative command workspace tailored for executive artificial intelligence operators and strategic leadership. The aesthetic fuses **Technical Minimalism** with **Tactile Glass Telemetry**: quiet, ultra-stable, and devoid of frivolous consumer decoration. It models the operational calm of flight deck avionics and private institutional terminals.

### Personality & Values
- **Quiet Authority:** Zero visual noise, aggressive layout stability, and absolute legibility under high cognitive load.
- **Auditable Rigor:** Cryptographic certainty, explicit verification levels, and provenance tagging treated as first-class UI citizens.
- **Operational Readiness:** Live system states (Termux daemon status, real-time voice latency, execution queues) are directly visible without interrupting the strategic workspace.

### Stylistic Execution
Surfaces are built on non-reflective graphite and near-black carbon foundations, intersected by razor-sharp structural boundaries and frosted glass-white accents. Subtle, desaturated semantic telemetry indicators (amber, emerald, cyan) deliver immediate system feedback without visual alarms.

## Colors

The system uses an executive dark architecture grounded in deep graphite values. The palette eliminates pure RGB blacks in favor of layered charcoal tones that preserve depth and structural hierarchy.

### Core Canvas & Panels
- **Canvas Base:** `#121417` (Deep Graphite Canvas)
- **Surface Layer 1 (Cards/Workspaces):** `#1A1D21` (Tactical Elevation)
- **Surface Layer 2 (Raised Modals & Insets):** `#22262B` (Interactive/Active Containers)
- **Structural Borders (Hairline Subdued):** `#282C34` (Grid lines, layout dividers)
- **Structural Borders (Focus/Active):** `#333842` (Component perimeters, card borders)

### Monochromatic Foreground Hierarchy
- **Primary Text & Glass-White Accents:** `#F0F2F5` (Optic White, 96% opacity)
- **Secondary Text:** `#9BA1A6` (Muted Executive Slate)
- **Tertiary/Meta Text:** `#636A73` (Telemetry labels, disabled states)

### Functional Telemetry & Source Authority Tiers
- **Telemetry Cyan (`#06B6D4` / Surface `#06B6D41A`):** Termux, local daemon connections, dynamic streaming data feeds.
- **Telemetry Emerald (`#10B981` / Surface `#10B9811A`):** Verified primary authority (Tier 1 & Tier 2), operational execution clearance, voice engine online.
- **Telemetry Amber (`#F59E0B` / Surface `#F59E0B1A`):** Staged actions pending executive approval, mid-tier synthesis (Tier 3 & Tier 4), warning flags.
- **Telemetry Crimson (`#EF4444` / Surface `#EF44441A`):** Critical human-in-the-loop blocking actions, hardware disconnects, unverified sources (Tier 6).

## Typography

Typography balances rapid executive scanning with exact cryptographic clarity.

### Typographic Roles
- **Headlines (Geist):** Clean, structural, and neutral. Provides razor-sharp hierarchy in strategic summaries, analytical boards, and executive briefs.
- **Body Text (Inter):** Highly legible, neutral workhorse engineered for dense analytical reports, synthesized notes, and long-form transcripts.
- **System Telemetry & Metadata (JetBrains Mono):** Applied rigorously to all system feeds, execution payloads, source authority tier chips, timestamp stamps, and hardware monitors.

### Composition Rules
- System labels and telemetry tags must always render in uppercase via `label-sm` or `label-md` with tracking between `+0.04em` and `+0.06em`.
- Proportional numbers are prohibited in telemetry feeds, latency counters, and token meters; enforce tabular figures (`font-variant-numeric: tabular-nums`).

## Layout & Spacing

The layout model is an asymmetric 12-column terminal grid designed to maximize information density without clutter.

### Layout Model
- **Desktop (1440px+):** Fixed-width side rail (280px) for Hardware Status, Termux daemons, and Source Vault trees. The main staging canvas spans the remaining width, divisible into an 8-column workspace (intelligence syntheses, media scrubbers) and a 4-column contextual panel (Action Lifecycle, approval logs, voice audio telemetry).
- **Tablet (768px - 1439px):** Side rail collapses into a compact 56px telemetry icon strip. Main workspace and action rail stack into a unified dual-pane view with a sticky bottom command trigger.
- **Mobile (<768px):** Single-column stacked workflow. The bottom area is strictly reserved for the persistent Voice State bar and Action Lifecycle approval drawer.

### Grid Rhythm & Rules
- Baseline layout aligns strictly to a 4px sub-grid with an 8px modular step rhythm.
- Spacing within dense analytical panels must stay constrained to `space-sm` (8px) and `space-md` (12px) to guarantee simultaneous viewport visibility of the prompt canvas, provenance tags, and action triggers.

## Elevation & Depth

Visual hierarchy uses physical stratification over artificial lighting: tonal surface tiers, low-contrast hairline outlines, and frosted glass-white accents.

### Tonal Stratification
- **Ground Floor (Base Canvas, `#121417`):** Non-interactive backdrop. Carries terminal grid separators and background canvas panels.
- **Surface Elevation 1 (`#1A1D21`):** Functional panels (Knowledge Vault lists, Media scrubber panels, System Feed monitors). Framed by a 1px solid border of `#282C34`.
- **Surface Elevation 2 (`#22262B`):** Hovered items, interactive rows, active contextual cards, and sliding drawer containers.

### Hairline Ghost Borders
No heavy drop shadows are permitted on standard cards. Structure is defined by 1px borders using `#282C34`. When a module changes state to active or selected, its border sharpens to `#333842` or an accent tint (`#06B6D440` or `#10B98140`).

### Glass-White Accents & Overlays
Floating executive overlays (Approval Banners, Live Audio Modals, Command Palettes) utilize a Frosted Glass-White treatment:
- **Background:** `rgba(24, 27, 32, 0.82)`
- **Backdrop Blur:** `16px`
- **Top Rim Light:** An inner box shadow of `inset 0 1px 0 0 rgba(240, 242, 245, 0.12)` providing a crisp edge.
- **Shadow:** `0 12px 32px -4px rgba(0, 0, 0, 0.65)`

## Shapes

The interface employs a disciplined, micro-radii geometry (`roundedness: 1`), conveying architectural precision and tool-like utility rather than consumer softness.

### Geometry Rules
- **Base Surfaces & Cards:** `0.25rem` (4px). Clean, technical edges that butt neatly against adjacent grid borders.
- **Interactive Inputs, Buttons, & Sub-panels:** `0.25rem` (4px).
- **Executive Approval Banners & Modals:** `0.5rem` (8px, `rounded-lg`).
- **Telemetry Badges, Source Authority Tiers, & Live Voice Indicator:** Strictly pill-shaped (`9999px`) to contrast against rectangular content blocks and signal instantaneous status.

## Components

### 1. Buttons & Triggers
- **Primary Executive Trigger (Commit/Authorize):** Background `#F0F2F5`, foreground `#121417`, font `Geist` weight 500. Subtle top inner highlight. Hover: `#FFFFFF` with slight outer glow `0 0 12px rgba(240, 242, 245, 0.25)`.
- **Secondary Control (Inspect/Configure):** Background `#1A1D21`, border 1px solid `#333842`, text `#F0F2F5`. Hover: background `#22262B`, border `#636A73`.
- **Destructive / Abort Trigger:** Background `#EF444414`, border 1px solid `#EF444440`, text `#EF4444`. Hover: background `#EF444426`.

### 2. Action Lifecycle Approval Banners
Persistent banners parked atop or anchored to the bottom of the viewport when an action is staged:
- Structure: Frosted glass panel (`rgba(24, 27, 32, 0.90)`), 1px solid `#F59E0B50` border.
- Left block: Pulsing amber telemetry badge `STAGED_EXECUTION` in `JetBrains Mono`.
- Center block: Concise intent summary (e.g., `"DISPATCH EMAIL TO STRATEGY BOARD"`) accompanied by payload preview icon.
- Right block: Binary executive controls: `"DISMISS [ESC]"` (text-only `#9BA1A6`) alongside `"AUTHORIZE [⌘+ENTER]"` (solid glass-white `#F0F2F5`).

### 3. Knowledge Vault: 6-Tier Source Authority Tags
Monospaced, compact pill tags affixed to retrieved intelligence chunks and citations:
- **Tier 1 (Canonical/Direct Feed):** Border `#10B981`, text `#10B981`, background `#10B9811A`. Tag label: `AUTH-1: CANONICAL`.
- **Tier 2 (Official Corporate Source):** Border `#06B6D4`, text `#06B6D4`, background `#06B6D41A`. Tag label: `AUTH-2: PRIMARY`.
- **Tier 3 (Verified External/Media):** Border `#636A73`, text `#9BA1A6`, background `#22262B`. Tag label: `AUTH-3: EXT_VERIFIED`.
- **Tier 4 (Secondary Synthesized):** Border `#333842`, text `#636A73`, background `#1A1D21`. Tag label: `AUTH-4: SYNTHESIS`.
- **Tier 5 (Unconfirmed Web Data):** Border `#F59E0B60`, text `#F59E0B`, background `#F59E0B14`. Tag label: `AUTH-5: UNCONFIRMED`.
- **Tier 6 (Speculative/LLM Raw):** Border `#EF444460`, text `#EF4444`, background `#EF444414`. Tag label: `AUTH-6: HEURISTIC`.

### 4. Voice States & Waveform Telemetry
A compact status dock indicating the AI Chief of Staff speech engine:
- **Idle:** Solid pill, border `#282C34`, text `#636A73`, dot marker `#636A73`. Label: `VOICE: STANDBY`.
- **Listening:** Emerald accent, dot marker pulsating `#10B981`, visualizer displays 4 vertical bars varying in amplitude dynamically. Label: `VOICE: LISTENING [0.04s]`.
- **Reasoning / Processing:** Cyan accent, circular tracking spinner in `#06B6D4`. Label: `VOICE: SYNTHESIZING`.

### 5. Media & YouTube Intelligence Workspace
- Inset media player bounded by `#282C34` with an integrated scrubber.
- Scrubber contains color-coded temporal pins matching key insight moments, synchronized with a real-time markdown transcription pane on the right.
- Extraction controls (`"CLIP TAKEAWAY"`, `"EXTRACT PROVENANCE"`) surface on timestamp hover.

### 6. Termux & Device Readiness Status
Mini-terminal telemetry matrix in the navigation rail:
- Monospace key-value readouts: `DAEMON: ACTIVE`, `SSH: LOCALHOST:8022`, `BATT: 94% [AC]`.
- Visual health check: Single-pixel live status dot (Emerald = Connected, Amber = Degraded, Red = Offline).

### 7. Form Controls (Input & Selection)
- **Text Inputs:** `#121417` background, 1px border `#282C34`. Typography `Inter` 14px. On focus: border `#06B6D4`, subtle inset shadow.
- **Checkboxes & Radios:** Sharp square / crisp disc forms, `#1A1D21` fill with `#333842` border. Checked state uses solid `#F0F2F5` fill with deep graphite interior tick.
