# Engola Media Intelligence — v0.5

Engola now has a first-class Media Intelligence workspace for YouTube.

## What it does
- Accepts a YouTube watch/shorts/embed/short link.
- Embeds the player directly inside Engola using YouTube's official embedded player.
- Retrieves public oEmbed metadata where available.
- Provides a **Study & learn** action that uses Engola's web-search-enabled AI to verify the topic, find authoritative related sources, identify uncertainty, and store a private study note in Engola memory.

## Important limitation
The v0.5 prototype does not scrape or claim to consume arbitrary video audio. It only says it has watched/heard a video when actual content is supplied through an authorized source. For deeper transcript-based learning, add an authorized YouTube/Google OAuth integration and a transcript/caption ingestion pipeline that complies with YouTube's API terms.

## Future media roadmap
- YouTube search/feed via YouTube Data API with an owner-authorized API key.
- Channel and playlist monitoring.
- Authorized captions/transcript ingestion where permitted.
- PDF/web/article ingestion beside the player.
- Time-stamped notes and citations.
- Private knowledge graph linking media to Engola memory, projects and career/tax research.
- Voice playback using an original documentary-style voice; no imitation or cloning of a living narrator's distinctive voice.
